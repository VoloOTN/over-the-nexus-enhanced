## BUG found by the stall detector and FIXED (scratch/revolt_gdb.py, build/cpu_battery/gdb_rv1)
- The first build hung: the cost stub was entered 165,981 times (the native cost never finished). Cause: I wrote the "any card" hand handler as 0x0223CB15; the function starts at 0x0223CB18 (`push {r3,r4,lr}`), 0x0223CB14..17 is the previous function's literal pool, so the row handler ran garbage. Correct = 0x0223CB19. revolt.py now asserts at install that the three handler / enumerator addresses start with a push.
