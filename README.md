# Over the Nexus Enhanced

This repo contains the code for three things:
1) The code which makes Over the Nexus Vanilla+ romhack
2) The code which makes Over the Nexus Enhanced romhack
3) The code which builds the Over the Nexus Randomiser

Most of the code here should be used as reference but I recommend using [CardWorkshop](https://github.com/BlueKitkallos/CardWorkshop) by BlueKitKallos as it will set you up for greater success!

## Instructions

The patches are available as .xdelta patches from the (releases page)[https://github.com/VoloOTN/over-the-nexus-enhanced/releases], please apply them however you see fit! e.g. https://kotcrab.github.io/xdelta-wasm/

This should be applied to a unpatched copy of a european (BYYP) version of over the nexus.

## Vanilla+
The vanilla+ patch contains the following:
- Faster CPUs and Duel 'View' Mode (Thanks BlueKitKallos!)
- 32 new cards mostly from EXCV and GENF. Or a selection of TCG-Exclusives e.g. Boggart Knight and Darksoul
- All downloadable banlists are available without needing to download them!
- An option to disable the banlist altogether (no need to cheat)!
- The All-at-Random pack is always available
- Every card in the game can be bought from the card shop now (including Alt Arts and the God Cards)
- Armory Arm uses TCG rulings
- Vylon Element now does not miss timing

## Enhanced
In addition to the vanilla+ patch, the enhanced edition patch contains:
- 130 additional cards! I am not going to spoil them here... You will just have to find them!
- Updated decks for all CPUs and Story Mode NPCs!! These should be more challenging without being unfun to play again. However there could be instances where the CPU is just a hopeless pilot.
- A custom banlist which is a mix between Sept 2010 and Sept 2011 banlists (I want BLS and Fishborg Blast together!)
- Various small tweaks to cards, nothing too egregious...
